# Adegbite Oladimeji Portfolio

Personal portfolio website for Adegbite Oladimeji, a creative designer, web developer, video editor, cinematographer, and digital media consultant.

Live site: https://dejiade-coder.github.io/personalweb/

## Contents

- `index.html` - main portfolio page
- `styles.css` - responsive visual styling
- `script.js` - navigation, filters, and accordion interactions
- `content.json` - editable portfolio content used by the page
- `uploads/` - project and flyer images
